# Aerowave Orb Creator

An cool Frutiger Aero styled desktop application designed for creating, customizing, and exporting glossy aero orbs with an immersive UI.

![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)

![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20macOS%20%7C%20Linux-lightgrey.svg)

---

## Key Features

* **Dynamic UI Themes**: Switch seamlessly between unique aesthetic themes:
  * **Dark**
  * **Aqua**
  * **Eco**
  * **DORFic**
* **Layer Management**: Add, stack, align, and scale **Orbs**, **Reflections**, and **Glows** with magnetic canvas snapping.
* **Immersive Audio**: Custom made jingles and notification sounds.
* **High-Resolution Export**: Export your creation as a transparent and custom sized PNG up to 10,000px.

## Running the Pyinstaller (Windows)

If you just want to run the app without installing Python:
1. Head over to the [Releases](../../releases) tab on the right.
2. Download the latest **`AerowaveOrbCreator.exe`** attached to **v1.0**.
3. Run it directly. No setup required!
